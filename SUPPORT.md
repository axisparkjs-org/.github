# Support

Thanks for using AxiSpark.js! Here is how to get help.

## Documentation

Most questions are answered in the [official documentation](https://axisparkjs.com/), which includes getting started guides, plugin references and the API documentation. The [samples](https://github.com/axisparkjs/axispark/tree/main/samples) folder contains working examples of most features.

## Bugs and Feature Requests

If something is not working as expected, or you are missing a feature, open an issue in the [axispark repository](https://github.com/axisparkjs/axispark/issues/new/choose) using the matching template. See the [contributing guidelines](CONTRIBUTING.md) for details.

## Security Issues

Do not open public issues for security vulnerabilities. Follow our [Security Policy](SECURITY.md).
